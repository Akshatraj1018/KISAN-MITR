# 🌾 Kisan Mitr — Frontend Application
**Next-Gen Edge-First AI Agricultural Operating System for Indian Farmers**

Built for **Innovathon 2.0 • NIT Rourkela 2026** by **Team Loop**.

---

## ⚡ Highlights
- **Krishi Sathi Multilingual Voice AI**: Edge-native, zero-latency natural voice conversational assistant supporting Hindi, Odia, and Indian English with 100% soothing female voice (`Lekha` / `Tara`).
- **Edge Vision Diagnostics**: Instant crop disease classification and PyTorch soil health assessment.
- **Glassmorphic Agricultural HUD**: Dynamic real-time weather alerts, mandi price telemetry, and soil NPK advisories.
- **Progressive Web App (PWA)**: 100% offline-resilient with local caching and service workers.

---

## 🚀 Tech Stack
- **Framework:** React 19 + Vite 7
- **Styling:** Vanilla Glassmorphism + Modern Emerald Theme + Lucide Icons
- **Voice AI:** Web Speech Synthesis & Recognition API
- **Authentication:** Firebase v11 (Google Mail OAuth + Smart Email Auth + Mobile OTP)
- **Deployment:** Progressive Web App (PWA) ready

---

## 💻 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev
```

App will run at `http://localhost:5173`.
